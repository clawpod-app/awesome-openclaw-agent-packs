# Live Music Booking

> Route DIY tours, discover independent small stages across all 50 US states, and identify who books each room using [No Stairs Please](https://nostairsplease.com/).

## Skills Included
- **venue-booking**: Query small-stage venues by city/corridor via the [No Stairs Please MCP](https://nostairsplease.com/mcp) endpoint and draft tailored booking pitches.

## Quick Start
1. Copy `packs/live-music-booking/` to your OpenClaw workspace
2. Connect the [No Stairs Please MCP](https://nostairsplease.com/mcp) endpoint
3. Browse [all venues](https://nostairsplease.com/venues) or ask for rooms along a tour route
