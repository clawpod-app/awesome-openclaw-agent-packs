# Tools Configuration

## Required
- Web Search (built-in) -- for trending topics and industry conversation monitoring

## Recommended OpenClaw Plugins

- [TweetClaw](https://github.com/Xquik-dev/tweetclaw) (`@xquik/tweetclaw`) - X/Twitter search, replies, follower export, media workflows, monitors, and approval-gated actions. Install with `openclaw plugins install clawhub:@xquik/tweetclaw`.

Xquik is an independent third-party service. Not affiliated with X Corp. "Twitter" and "X" are trademarks of X Corp.

## Recommended MCP Integrations
- Twitter/X API -- post tweets, read analytics
- LinkedIn API -- publish posts, track engagement
- Buffer/Typefully -- schedule posts and manage queue
- Notion -- store content calendar and idea bank
